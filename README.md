# huiji 旧版数据库检索器

对 `huiji/dotawiki-master`（PyQt5 旧版 wiki 数据编辑器）自带的 **7.32e 时代本地数据库**做离线检索。
界面与交互沿用现行 `D:/wiki/tagsearch`（技能 Tag 检索器）的模式：**且 / 或 / 反选**三类条件可叠加、
模糊匹配、结果表格 + 详情弹窗 + CSV 导出、简/详两种展示。

## 快速开始

- **双击 `index.html`** 即可使用（纯静态，无需服务器、无需联网）。
- 或双击 `start.bat`（用默认浏览器打开本页）。

## 数据来源与构建

数据由 `build_data.py` 从旧编辑器数据库与 7.32e 技能源页面生成：

```bash
python build_data.py [数据库目录] [输出data.js路径] [huijidata目录]
# 默认：../dotawiki-master/dotawiki-master/database 与 ../huijidata
```

> ⚠️ **版本隔离（铁律）**：本检索器**严禁引入现行网页 wiki（7.4x）的任何数据**。
> 旧版 huijiwiki（7.32e）与现行 wiki 是两个独立版本，混用会污染旧版快照。
> 本工具只使用 7.32e 的 KV 与技能源页面（`huijidata/`，由下载器从 huiji 抓取），不读取任何现行 wiki 数据。

| 来源 | 生成集合 |
| --- | --- |
| `text_base.json`（技能 KV） | **技能**基础字段 + **英雄** + **物品** + **非英雄单位** |
| `huijidata/<分类>/*.json`（技能源页面，7.32e，已按英雄/物品/单位等分类） | 补充 **技能** 的包含效果/技能行为/独立机制/无敌/减益免疫/状态抗性 |
| `mech.json` | **机制**（190 条，含简述原文；亦提供机制代码→名称映射） |
| `name_base.json` | **曾用名**（3720 条：历史/原生/衍生） |
| `version_base.json` | **版本更新**（288 个版本，0.6 ~ 7.32e 的更新条目全文） |
| `entry_base.json` | **词汇注释**（10 条叠加方式） |

中文名来自 `text_base[翻译]`（`DOTA_Tooltip_ability_*` / `npc_dota_hero_*` / `DOTA_Tooltip_Ability_item_*` 键）。

## 技能集合的标签体系（双来源，均为 7.32e）

标签来自 7.32e 的两类旧版数据，均可离线构建，界面 chip 统一为默认色。

### ① 游戏 KV 派生（7.32e）

| 维度 | KV 字段 | 说明 |
| --- | --- | --- |
| 施法类型 | `AbilityBehavior` | 被动/无目标/单位目标/点目标/矢量目标/持续施法/开关·切换/立即施法/隐藏/不可学习…；AOE 令牌给出 点目标+范围指示 |
| 目标 | `AbilityUnitTargetTeam` / `AbilityUnitTargetType` | 势力（敌方/友方/敌我/自定义）× 类型（英雄/普通单位/建筑/树/自定义） |
| 技能免疫 | `SpellImmunityType` | 沿用 7.32e 词汇：敌军有视/无视/友军有视/友军无视/友军有视敌军无视 |
| 驱散情况 | `SpellDispellableType` | YES→弱驱散、YES_STRONG→强驱散、NO→无法驱散 |
| 伤害类型 | `AbilityUnitDamageType` | 魔法/物理/纯粹/无类型 |
| 升级 | `HasScepterUpgrade` / `HasShardUpgrade` | 神杖升级 / 魔晶升级 |
| 类别 | 名称前缀 + Behavior | 天赋技能（special_bonus_*）/物品技能/隐藏技能/非学习技能 |
| 归属 | 名称前缀解析 | 归到具体英雄/物品（如 `earthshaker_*` → 撼地者） |

### ② 技能源页面机制字段（7.32e）

来自 `huijidata/` 的技能源页面，数字代码经 `mech.json` 词典解码：

| 维度 | 来源字段 | 说明 |
| --- | --- | --- |
| 包含效果 | `效果/<组>/<子>/名称` | 沉默/锁闭/眩晕/缴械/破坏/缠绕/治疗/隐身…（231 种） |
| 技能行为 | 技能抵挡/反弹/共享/窃取、幻象、破坏、持续施法、躲避、缠绕、即时攻击、视野、真实视域 | 按代码语义转成「技能抵挡/可被窃取/幻象继承/提供空中视野…」 |
| 独立机制 | `独立机制/*/机制名` | 强制位移/双击施法/禁用帮助/无种类打断/朝向固定…（45 种） |
| 无敌 | `无敌`（效果级） | 仅非隐藏无敌/无敌和隐藏/部分无敌 |
| 减益免疫 | `减益免疫`（效果级） | 有视/无视减益免疫 |
| 状态抗性 | `状态抗性`（效果级） | 无视状态抗性/减少持续时间/减少降低效果的百分比/减少强制位移效果 |

**匹配范围**复选框按 **14 个维度**呈现（KV 8 项 + 源页面 6 项），全部来自 7.32e 快照。

> 说明：旧编辑器的 `json_base.json` 为空，这些效果/行为标签改由 `huijidata/` 的技能源页面补齐；
> huiji 上已删除（404）的源页面对应技能仅保留 KV 派生标签。`huijidata` 目录缺失时构建自动退化为仅 KV 标签。

## 检索语义

- **且**：须同时含全部标签；**或**：至少含其一；**非**：含任一即剔除。三类同时生效。
- **模糊匹配**：标签名按子串展开（如「驱散」→ 弱驱散/强驱散/无法驱散）；仅作用于标签，不影响「名称包含」。
- **名称包含**：始终按子串匹配（不区分大小写），可与其他条件组合。
- 同名标签只可能存在一个 id（本工具按 (名称, 维度) 去重），输入后下方会实时显示解析结果。
- 「版本更新」集合的标签 = 各版本更新条目中出现的**实体名**（英雄/物品/单位），用「或」条件即可查某实体的历次改动；
  详情弹窗展示该版本全部更新条目（已去除 wiki 模板 markup）。

## 已知边界

- 数据快照为 **7.32e（2023-03-07）**，与现行 7.4x 差约 30 个版本；KV 字段可能已增删（如命石相关字段缺失）。
- 旧编辑器的 `json_base.json` 为空；本工具改用 `huijidata/` 的技能源页面补齐效果/行为类标签。huiji 上已删除（404）的源页面（约 46 个）对应技能仅保留 KV 派生标签。
- 「无法驱散」条目中哪些同时可被死亡驱散，KV 不区分；源页面 `驱散` 字段虽更细，本工具仍以 KV 的弱/强/无法驱散三分类为准。
- **版本隔离**：旧版（7.32e）与现行（7.4x）是两个独立版本，本检索器不混入任何现行网页数据。重建时重跑 `build_data.py` 即可；`huijidata` 缺失时自动退化为仅 KV 标签。
